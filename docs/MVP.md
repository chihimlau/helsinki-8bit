# MVP 定義

## 區域
`helsinki-kruununhaka`（約 1km x 1km）。
原因：低樓層、新古典主義建築、一個非常容易認得的地標（白色 Cathedral + 綠色圓頂），範圍細，適合先把流程走通。

## 使用者可以做的事（Must）
1. 拖動地圖（手機單指、電腦滑鼠）
2. 縮放（手機雙指、電腦滾輪）
3. 點建築：橙色輪廓高亮
4. 點地標 pin：彈出資訊卡（名稱 + 一句簡介，暫時沒有故事）
5. 地標清單：點一下，鏡頭移到該地標
6. 日 / 黃昏切換
7. 載入快，手機順暢

## 不在 MVP（之後再說）
- 旋轉相機（MVP 固定 45° 方位角）
- 人物、NPC、走路、故事、多人
- 天氣、季節、交通
- 第二個區域（helsinki-kluuvi 在 M5）
- App 版本

## 驗收清單
- [ ] 手機打開預覽網址，3 秒內見到畫面
- [ ] 認得出 Senate Square 和 Cathedral
- [ ] 拖動、縮放順暢
- [ ] 點 Cathedral 有高亮和資訊卡
- [ ] 效能預算全部通過
- [ ] 頁面有 Helsinki 3D 和 OSM 的來源標示
